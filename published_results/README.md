# Published result summaries

Raw DOMINO simulator artifacts remain under gitignored `runs/`. Small audit summaries generated by `scripts/publish_results.py` belong here so that commits can be inspected without transferring replays/checkpoints.

Every published result should record the repository SHA, paired SR/MS analysis, and available FULL event coverage. Treat developmental/pilot outputs as such; do not relabel them confirmatory after changing the protocol.
